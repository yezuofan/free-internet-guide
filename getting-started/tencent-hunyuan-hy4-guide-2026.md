## 和 Hy3 相比升级了什么

| 指标 | Hy3 正式版 | Hy4 preview | 变化 |
|:----|:----------|:------------|:-----|
| 总参数 | 295B | 770B | 2.6 倍 |
| 激活参数 | 21B | 49B | 2.3 倍 |
| 上下文长度 | 256K | 1M | 4 倍 |
| 开源协议 | 部分开放 | Apache 2.0 全开放 | 权重、推理代码全放 |

腾讯直接拉软件工程、游戏、金融、安全各条线的顶尖专家参与高质量数据建设（Co-Design），模型在真实任务上的表现比纯堆参数更扎实。

## 性能亮点

内部盲测（163 名专家、203 个工程任务）：Hy4 preview 均分 2.99/4，略优于 GLM-5.3（2.92/4.00）和 Kimi K3（2.94/4.00）。四个重点场景：

1. **软件工程**：长程开发任务理解/规划/调试/验证增强，配合 CodeBuddy 使用效果更明显
2. **办公分析**：长文档理解 + 表格数据处理，1M 上下文可直接丢整本手册
3. **游戏开发**：媒体实测生成游戏能自行纠错，代码生成 + 执行验证闭环不错
4. **科学研究**：长程推理与多步实验设计能力，适合论文阅读与实验方案生成

## 怎么用：四条路径

1. **免费体验**：腾讯元宝、ima 已接入 Hy4 preview，直接选模型即可，适合先感受 1M 上下文（丢整本电子书/长合同进去问问题）
2. **深度集成**：WorkBuddy（首发接入，办公场景）、CodeBuddy（编程场景），开发者直接用这两个产品最省事
3. **API 接入**：腾讯云 TokenHub 开通，模型名 `hunyuan-hy4-preview`（以官方控制台为准），按量计费
4. **国际调用**：OpenRouter 已上架，统一 OpenAI 兼容格式，海外开发者/统一 API 团队友好

## FAQ

- **免费吗？** 模型开源（Apache 2.0）可自部署；官方 API 按量计费，元宝/ima 可免费体验
- **1M 上下文能干什么？** 约 70-80 万英文单词或一整本长篇小说；整仓代码分析、长合同问答、几十页报表一次性处理
- **和 GLM-5.3、Kimi K3 怎么选？** 三者同属开源第一梯队，盲测互有胜负；看生态：腾讯系产品用 Hy4 最顺，已用智谱/月之暗面 API 的团队没必要迁移
- **排队问题解决了吗？** 8/31 高峰排队是首发接入后的短期现象，官方周末连续扩容，现基本稳定
- **本地能跑吗？** 770B 总参数体量对硬件要求高，个人设备不现实，建议走 API 或等社区量化版本
