## Perplexity 是什么？

Perplexity 是一个**AI搜索引擎**，但它和 Google/Bing 有本质区别：

| 对比维度 | Google/Bing | ChatGPT | Perplexity |
|:--------|:-----------|:--------|:----------|
| 回答方式 | 给链接列表 | 纯文字回答（可能编造） | **文字回答 + 原文链接** |
| 信息时效 | 实时 | 训练截止日 | **实时联网** |
| 引用来源 | 无 | 无 | **每一句话都有出处** |
| 适合场景 | 简单事实查询 | 创作/推理 | **研究/查资料/写报告** |

### 核心能力

1. **实时联网搜索**：能搜索最新新闻、股票、学术论文
2. **带来源的回答**：每句话后有 `[1]` `[2]` 标注，点击可跳转原文
3. **多角度研究**：自动搜索多个来源，给出综合观点
4. **学术友好**：能直接引用 DOI 链接

