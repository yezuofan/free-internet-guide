## 8个实战Prompt模板

### 1. 代码调试（推理模式）
```
请分析以下代码中的bug。先列出3-5个可能原因，
逐个验证，最后给出修复方案：
[粘贴代码]
```

### 2. 复杂数据分析
```
分析这份数据集（附CSV），输出：
数据概览 → 趋势分析 → 异常挖掘 → 建议
```

### 3. 长文写作
```
将以下会议录音整理成正式纪要：
按议题分节，含讨论要点、结论、待办事项
```

### 4. 多文件重构（Codex场景）
```
重构项目：[描述]
分步实施，每步验证，标注兼容性问题
```

### 5. 竞品分析
```
对比3款产品的功能、定价、用户、优劣势
先总表 → 逐产品展开 → 推荐排序
```

### 6. 跨工具工作流
```
搜索→整理→生成幻灯片→输出兼容格式
开启浏览器搜索，用Codex完成每一步
```

### 7. 科研探索
```
理解问题背景 → 调研文献 → 提出2-3种思路 → 可行性分析
用GPT-5.5 Pro模式，输出含公式、代码、引用
```

### 8. 文档创建
```
项目管理模板：项目概述 + 时间线 + 任务分配 + 风险矩阵 + 周报
```
