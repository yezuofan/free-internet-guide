# Grok 4.7 上手指南 2026：参数涨四成、价格没动，哪些活能交给它

> 原文：https://huanghaiwan.com/ai/grok-4-7-guide-2026/

美国当地时间 9 月 21 日，SpaceXAI 发布 Grok 4.7。官方口径是「面向编程与知识工作的最强模型，速度是同类两倍、价格只有一半」；发布第二天，程序员开始晒它生成的**没有轮子的 3D 自行车**。

两件事都是真的。这版本从 7 月下旬开始预告，时间前后改过五次（「四周之后」→「十天之内」→「还需要几天」），拖了近两个月才交卷。改动集中在三处：基座从 1.5 万亿参数涨到 2.1 万亿（约 +40%），强化学习训练周期拉长，训练样本明显向「需要数小时才能完成的问题」倾斜。

**一句话结论：这是一次方向明确、幅度克制的升级——执行类长任务的能力真涨了，视觉类生成仍然不稳；API 单价没动，但单任务花销可能上涨，账要按任务算。**

## 太长不看

| 你的情况 | 结论 |
|:---|:---|
| 跑代码 Agent、长任务、仓库级重构 | 可以上，终端操作基准接近翻倍 |
| 只想问答、写文案 | 主流模型都能满足，不必折腾接入方式 |
| 做 3D、动效、可视化、SVG 生成 | 先别交，实测翻车最集中在这块 |
| 靠旧框架或第三方工具调用 | 先确认框架已适配，否则可能不如上一代 |
| 只算单价就以为省钱 | 单任务 token 消耗可能涨一倍以上 |

## 一、跑分拆开看：哪些是真涨

| 基准 | 上代 | 4.7 | 指向 |
|:---|:---|:---|:---|
| Terminal-Bench 4.0 | 20.3% | **38.0%** | 终端操作与命令执行 |
| CursorBench 4.0 软件工程 | 40.4% | **46.3%**（xhigh 档 71.0%） | 仓库级改代码 |
| DeepSWE v1.1 长时编程 | — | 71.0% | 跨文件多轮迭代 |
| AA-Briefcase 多小时办公 | — | 1657 Elo | 模拟专业岗位长时作业 |
| 电气工程专业测试 | — | 64%（该榜第一） | 垂直领域任务 |

新增的 xhigh 推理档，就是让模型在难任务上多花算力。CursorBench 那组 46.3% 与 71.0% 的差距，基本就是这个开关的差距。

没涨的是综合智能指数：Artificial Analysis 给 46 分，全球第六；同一天小米开源的 MiMo V2.6-Pro 也是 46 分。这一代是**追平同梯队，不是拉开身位**。

## 二、三个翻车点

**一、视觉与 3D。** 生成 3D 场景、可视化程序时结果不稳，有「3D 自行车没有轮子」的，也有经典「鹈鹕骑自行车」SVG 动画里角色与车子运动关系错乱的。有开发者拿 Kimi 3 同题对比后说效果不如对方，成本还是对方三倍。

**二、接入方式决定成败。** 安全公司 XBOW 用 50 项漏洞测试跑了两轮：早期候选版接进**原有框架**，成绩略逊于上代；换成基于官方 Agent 框架的系统，结果才反转。同一个模型，两套工具链，结论相反。

**三、长任务仍差一档。** 有测算显示，长程自主任务上它仍落后 Claude Fable 5.1 近 20 个百分点。官方这一代几乎把「坚持更久」直接写成了卖点。

正面的例子也有：有用户汇总的 10 个真实任务里，最扎眼的一笔是它揪出一处价值 14.6 万美元的错误。做财务、审计、对账这类工作，这种能力比写漂亮文案实在。

## 三、价格没涨，账单可能涨

标准档定价与上代一致：**每百万 token 输入 2 美元、输出 6 美元**；另有高速版，速度翻倍、价格也翻倍。横向比：GPT-5.6 Sol 是输入 4 美元、输出 20 美元；Claude Fable 5.1 是输入 10 美元、输出 50 美元。

但已有实测提到，部分任务上单次消耗的 token 涨了 125% 以上——它想得更久、检查得更细，思考过程同样计费。按任务算钱的差别更直观：本代 xhigh 档约 6 美元/百万输出，小米 MiMo V2.6-Pro 约 0.87 美元、Flash 约 0.28 美元，而两个模型当天在同一个榜单上都是 46 分。

**做法就一句：高频轻任务用便宜模型，难任务、长任务才开高档位。**

## 四、四个入口怎么选

发布当天它已上四条通道：xAI API、官方 Agent 构建平台、Cursor，以及第三方编码工具、模型路由与云平台，此后逐步向 GitHub Copilot 用户开放。

| 你要干的事 | 走哪个入口 | 先确认 |
|:---|:---|:---|
| 改代码仓库、跑长任务 | 官方 Agent 构建平台 | 模型版本、账号额度、是否开高速模式 |
| 在熟悉的编辑器里改代码 | Cursor | 模型选项、用量上限、编辑器计费规则 |
| 从自己的应用调用 | xAI API | Key、余额、精确模型 ID |
| 流程挂在别的工具上 | 第三方工具 / 路由 | 该工具是否已提供这个版本 |

最常见的误判在最后一行：面向开发者的发布，**不保证**网页端和手机端每个账号都有同一个模型选择器。找不到先核对该应用有没有提供该版本，再怀疑账号问题。另外，工具订阅、API 余额、第三方网关账户是三套独立付费方式，要分别确认。

## 五、国内使用的现实路径

1. **把出口固定下来。** 登录位置频繁变化是风控里很重的一条，固定一条胜过不断找「更快的一条」。
2. **分开「浏览查询」和「养账号」。** 偶尔问几个问题，普通线路够；要长期保持登录、绑定支付、跑 API 余额的账号，需要出口身份更稳的方案。

## 六、边界：能交的和别交的

**能交：** 仓库级改代码、跑测试、修 CI、按日志排障、长文档整理与对账核查、需要持续工作几十分钟到几小时的执行类任务。实测里「揪出高额错误」「优化 Bot 效率」的案例都在这一区间。

**先别交：** 3D 建模与场景、动效与可视化编程、SVG 精细图形、需要精确空间关系的生成。要用就先拿小样本试一轮，别直接放进交付链路。

**要小心：** 把新模型硬塞进没适配的旧框架——这一代的能力高度依赖专用 Agent 框架的上下文管理与重试策略。

## 七、常见问题

**升级最值得的理由是什么？** 终端操作与长任务。Terminal-Bench 从 20.3% 到 38.0%，对应的是「让 Agent 真把命令跑起来、把结果拿回来」。

**价格真的一点没变？** 标准档没变；高速档、xhigh 档额外付费，难任务上的 token 消耗也会上升。看单价没变，看账单可能变了。

**别人说好用我试了却不行？** 大概率是接入方式不同。同一版本接进旧框架和接进官方框架，实测结论是相反的。

**网页端为什么看不到这个模型？** 面向开发者的发布不保证所有端账号都有同一选择器，先核对应用是否提供该版本。

**46 分够不够强？** 全球第六，第一梯队末到第二梯队头部。这一代重点不在通用智力，而在执行类任务的持续能力。

## 八、结语

Grok 4.7 是一次加量不加价的升级，不是降价。它最大的价值是把需要几小时的任务真的跑完，最大的短板是视觉生成仍不稳。正确用法是分工，而不是「有新模型就全换」。SpaceXAI 采用并行开发策略，Grok 4.5 是 7 月 8 日发布、到 4.7 只隔 44 天，2.5 万亿参数的下代已训练完成——**模型换代周期缩到 44 天以后，追版本号没有收益，配套流程跟不跟得上才是差距所在。**
