## 10个实战 Prompt 模板

### 1. 代码 Debug
```
我的代码跑不通，帮我分析：
[粘贴代码+报错信息]
1. 指明根本原因
2. 给出修复后代码
3. 解释为什么这样改
```

### 2. 文档分析
```
请分析以下文档：
[粘贴内容]
要求：100字概括 → 3个关键论据 → 局限性 → 数据可靠性
```

### 3. 翻译 + 本地化
```
将以下翻译成中文，要求：符合中文习惯、技术术语准确、长句拆短句
[粘贴原文]
```

### 4. SQL 生成
```
表结构：[CREATE TABLE]
需求：[自然语言描述]
请生成最优SQL + 索引建议 + 性能解释
```

### 5. 学习计划
```
我想学 [主题]，请给：先决条件 → 3个核心概念 → 学习路径 → 2个实战项目 → 免费资源
```

### 6. 代码 Review
```
请审查以下代码：[粘贴代码]
关注：性能瓶颈 → 潜在bug → 代码风格 → 安全问题
```

### 7. 数据分析
```
上传了数据文件，请：描述概况 → 找异常值 → 3个洞察 → 下一步建议
```

### 8. 写邮件
```
帮我写 [职场] 邮件给 [收件人]，目的是 [目的]，语气专业礼貌。
关键信息：[列出]
```

### 9. 会议总结
```
以下会议录音文字稿，请整理：核心议题 → 决议 → 待办（负责人+deadline）→ 争议点
[粘贴文字稿]
```

### 10. 提示词工程（教AI写提示词）
```
我想让AI做 [目标]，请帮我写一个高质量prompt，包含角色定位、输入输出格式、约束条件、示例。
```

## 7个进阶技巧

1. **文件上传**：支持 PDF/Word/Excel/PPT/图片（OCR提取文字），最大 100MB
2. **联网搜索**：对话框下方有 🌐 按钮，手动开启后获取实时信息
3. **多轮追问**：不满意就追问"再详细点"，DeepSeek 128K 上下文不怕长对话
4. **结构化输出**：prompt 末尾加"请用表格/Markdown/Bullet Points 输出"
5. **分步处理**：复杂任务拆成多轮对话，每次只处理一个子任务
6. **学习 R1 思考过程**：R1 会展示推理链，本身就是极好的学习方法
7. **中文优化**：这是 DeepSeek 的天然优势——直接用中文写 prompt，效果更好
