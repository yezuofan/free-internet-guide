## 核心能力

**1. 专业级图像编辑——改哪里，只动哪里**

- **魔棒工具**：圈住指定区域单独编辑，其余部分原封不动。产品换色、抹掉背景杂物，不用整张重画。
- **分割选区**：精准框选局部，单独调色、替换素材，适合边缘复杂的物体。
- **背景移除**：一键导出透明背景主体，丢进 PS / Canva 二次合成。
- **多参考图编辑**：单次生成最多输入 5 张图，自动融合，省掉手动拼接。

**2. 智能改尺寸——一张图，9 种比例随便切**

覆盖 1:2、9:16、2:3、3:4、1:1、4:3、3:2、16:9、2:1 九种主流比例。选好比例模型自动补全画面框架，不是简单拉伸裁切。一张主图适配详情页、banner、竖版封面，不用重新生成。

**3. 指令遵循与文字排版**

复杂画面自主规划版式；小字号文字渲染清晰度明显提升；多轮生成和编辑中稳定保留主体设定——改图改到第五轮，人物还是那个人物。

**4. 模板体系（15 种商用工作流）**

| 分类 | 模板 |
|:----|:----|
| 电商营销 | 电商商品图、UGC 买家秀、营销海报、商品换色、周边商品图 |
| 人像照片 | 专业形象照、照片编辑、照片拼贴、背景移除与更换 |
| 设计素材 | 吉祥物制作、图标制作、表情包制作 |
| 游戏素材 | 角色立绘、道具与 UI 套件 |
| 其他 | 创意重绘（Reimagine）、视频世界构建 |

**5. 一致性——给视频做素材铺路**

角色、场景、道具分别生成但风格全程统一。做短视频、动画、游戏设定的刚需——角色在不同场景不"换脸"，素材才能复用。

## 怎么上手

- **网页版（最推荐）**：打开 grok.com → 进入 Imagine 页面 → 选质量模式（Quality Mode），登录即用。
- **iOS / 安卓 App**：App Store / Google Play 搜索 Grok 下载，手机端同样支持魔棒编辑、背景移除。
- **X（推特）内直接调用**：对话里 @Grok 就能用，适合顺手改图做表情包。

**国内用户提醒：** Grok 服务部署在海外，从国内直连 grok.com 和 X 基本不可用，iOS 下载还需要海外 Apple ID。网络方案见下方推荐表。

## 常见问题

**免费吗？** 免费版 Grok 有有限图像生成额度，完整能力需 SuperGrok 订阅（$30/月）。

**质量模式是什么？** Image 2.0 在 Grok 里以"质量模式"提供，是当前最强的图像档位。

**API 什么时候开放？** 官方标注 "coming soon"，尚未开放。需要 API 批量出图现阶段建议先用国产方案。

**支持中文提示词吗？** 支持，文字渲染比前代明显改善，但中文小字精度仍不如 Qwen-Image-3.0。

**图能商用吗？** xAI 允许 Grok 生成内容用于商业用途，具体以服务条款为准。

**国内怎么用？** 需要先解决网络访问问题（grok.com、X、Google Play 均在海外），iOS 还需海外 Apple ID。
