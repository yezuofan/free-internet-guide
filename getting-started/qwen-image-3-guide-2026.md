## 三大核心升级

**1. 内容丰实：4.5k token 超长输入**

输入上限提到了 4.5k token，是前代的 4.5 倍。不用再把需求压缩成一句话，可以像给设计师写需求文档一样完整描述画面结构、文字内容、视觉风格、排版细节。报纸版面、影视分镜（20 个分镜的条漫一次生成）、数学试卷、PPT 页面都能一次到位。

**2. 细节真实：10px 小字精准渲染**

以前让 AI 在招牌、海报、书本上写正确的中文基本靠碰运气。Qwen-Image-3.0 把渲染精度做到 10px 小字，毛孔、发丝等微观质感也还原逼真。海报标题字、包装配料表、手写毛笔字一次生成，不用后期返工改字。

**3. 知识厚实：12 国语言 + 20 多款字体**

原生支持 12 国语言和 20 多款字体渲染，中英韩等多语种混合输入不出现缺字、乱码、错位。公式符号、几何图形、逻辑推导步骤融合的知识图解，以及复杂 UI 界面都能一次生成。

## 怎么用

**网页版（零门槛）：** 打开千问 AI 平台（chat.qwen.ai）→ 选择图像生成入口 → 输入描述，几秒出图。

**阿里云百炼 API（开发者）：** 开通百炼获取 API Key，调用 DashScope 图像生成接口：

```bash
curl -X POST https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis \
  -H "Authorization: Bearer 你的百炼API密钥" \
  -H "Content-Type: application/json" \
  -d '{"model": "qwen-image-3.0-standard",
       "input": {"prompt": "老北京胡同里，大爷坐在小马扎上就着蒜吃炸酱面"},
       "parameters": {"size": "1024*1024", "n": 1}}'
```

**Qwen Studio / 千问 APP：** 即将上线免费体验入口。

## 常见问题

**免费吗？** 千问 AI 平台提供基础体验入口，Qwen Studio 和千问 APP 即将开放免费试用。API 按张计费，标准版 0.18 元/张起。

**Pro 和 Standard 区别？** Pro 细节还原、复杂构图更强，适合商业高质量需求；Standard 主打性价比，日常够用。

**支持中文以外语言吗？** 原生支持 12 国语言，中英韩混合输入不缺字乱码，还能渲染 20 多款字体。

**图能商用吗？** 阿里云百炼企业版协议支持商用，具体以服务条款为准。

**国内能直接访问吗？** 可以，千问 AI 平台和百炼都是国内服务。
