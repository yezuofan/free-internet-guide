## 六、进阶技巧（用过5首以上再来看）

### 1. 结构化提示词法

把提示词拆成模块，效果远超随机描述：

```
Genre: [具体音乐风格]
Mood: [情绪关键词1, 关键词2, 关键词3]
Theme: [歌曲核心主题]
Lyrics Style: [歌词风格：叙事/诗意/口语化/对抗性]
Instrumentation: [主要乐器+辅助乐器]
Tempo: [BPM或快/中/慢]
Vocal Style: [歌手音色：男声/女声/童声/合唱/说唱]
Reference: [参考艺术家或歌曲]
```

### 2. Negative Prompt（反向提示词）

告诉 Suno **不要** 什么：

```
不要[不想要的元素：太吵/歌词太直白/副歌不够上头/节奏太慢/人声太假]
```

### 3. 分段生成法

1. 先生成纯音乐版本
2. 再生成人声版本
3. 最后混音（用剪映/PR等工具）

质量比一次性生成更高。

### 4. 善用 Remix 和 Extend

| 功能 | 用途 |
|:-----|:-----|
| **Remix** | 在原有基础上变化（风格/节奏/情绪） |
| **Extend** | 延长片段（生成更长的完整歌曲） |

### 5. 歌词优化技巧

| 技巧 | 例子 |
|:-----|:-----|
| 具体 > 抽象 | "讲述地铁末班车上的陌生人" 比 "城市孤独" 更有效 |
| 情绪词精准 | "心如刀割" 比 "难过" 更能触发正确情绪 |
| 场景细节 | "暴雨天躲在便利店门口" 比 "分手" 更动人 |
| 避免生僻字 | 中文发音会更标准 |
