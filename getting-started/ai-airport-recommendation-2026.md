## 一、连不上是两种病，处理方式相反

| 你看到的现象 | 真实原因 | 换节点有用吗 |
|:--|:--|:--|
| 提示所在地区不支持 / 服务不可用 | 出口在港、澳、大陆 | 有用，换日本、新加坡、台湾、美国 |
| 红字「unusual activity from your system」 | 出口 IP 风控分偏高 | 有用，换标注 AI 可用的节点 |
| Cloudflare 人机验证转圈，点完又弹 | IP 评分在临界线 | 部分有用，换低共享密度线路 |
| 能登录但回答变短变敷衍 | 账号或 IP 被降级软限制 | 只能缓解，先固定一条线养几天 |
| 一切正常，就是慢 | 这才是带宽与路由问题 | 有用，但优先级最后 |

地区资格这一层是硬门槛：OpenAI 的支持国家/地区名单里没有中国大陆、香港、澳门。香港从 2022 年 11 月 30 日 ChatGPT 上线起就没进过名单，2024 年 7 月起不支持地区的 API 调用也被切断。挂香港节点打开页面只会看到「not available in your country」。

## 二、出口 IP 的四个信任等级

从高到低：**住宅 ISP 家宽**（ASN 挂在 AT&T、Comcast、NTT 这类民用运营商名下）＞ **原生 IP**（注册地与 BGP 宣告一致，但归属仍是机房）＞ **普通机房 IP**（便宜机场的默认选项）＞ **已知代理出口池**。

比等级更容易被忽略的是共享密度：同一出口挂 5 个人和挂 500 个人，评分衰减速度不是一个量级。所以买之前值得问客服两句——AI 节点是单独分组还是全站共用？出口 IP 固定还是池子轮换？答得含糊的基本就是池子。

还有一条跟等级无关但同样致命：**长连接中途换 IP**。ChatGPT 网页版是流式输出，Codex、语音、长任务都跑 WebSocket，有些线路为负载均衡会在会话中途把你切到另一台落地机，现象是回答说到一半断了。测速软件一个都测不出来。

## 三、地区：最快的那个往往最没用

日本 30–60ms、新加坡 50–80ms、台湾低延迟但节点少、美国 150–200ms 起，这四个都在支持名单里。香港 20–40ms，全场最快，**但不在名单里，白给**。买之前看到主推「香港原生 IP」就先问：这套 IP 里有没有日本、新加坡、台湾出口？只有港台两地的，等于砍掉一半。

## 五、把 OpenAI 域名钉死在一条线上

最容易犯的错是让 ChatGPT 跟着「自动选择」到处跑，风控看到的就是一个一天换七个国家的账号。Mihomo（Verge Rev / ClashX Meta / Stash / OpenClash 都吃）：

```yaml
proxy-groups:
  - name: "AI"
    type: select          # 手动选，别用 url-test
    proxies: ["日本 01", "台湾 01", "新加坡 01", "DIRECT"]

rules:
  - DOMAIN-SUFFIX,openai.com,AI
  - DOMAIN-SUFFIX,chatgpt.com,AI
  - DOMAIN-SUFFIX,oaistatic.com,AI
  - DOMAIN-SUFFIX,oaiusercontent.com,AI
  - DOMAIN-SUFFIX,chat.com,AI
  - DOMAIN-SUFFIX,anthropic.com,AI
  - DOMAIN-KEYWORD,openai,AI
```

三个细节：组类型必须是 `select`，自动测速会在你没注意时换出口；节点名写实际的，别照抄示例；`chat.com` 很多旧规则集漏了，会出「主站能开、某个入口打不开」的怪现象。

## 六、四个常见误判

1. **把「解锁 Netflix」当「能跑 ChatGPT」**——两套检测体系，买前 Ctrl+F 搜套餐说明里有没有 ChatGPT。
2. **以为节点越多越好**——110+ 节点如果同属一批机房 IP 段，风控眼里就是同一个可疑来源。
3. **频繁切节点找快的**——最容易把账号搞废的动作，选定一条线跑满一周再说。
4. **把账号问题当线路问题**——同订阅同出口别人用得好你用不了，多半是账号侧：多人共用、注册信息不一致、行为异常。

## 七、买前四问，买后四步

付款前问客服：① 哪些节点标注 AI 可用，全站还是单独分组？② IP 是住宅、原生还是机房？③ 出口固定还是池子轮换？④ 有没有最短周期能先买一个月？答不出第三问的占多数，而它最影响长连接体验。

买完按顺序验：挑 AI 节点打开页面看是否地区限制 → 对话十分钟数弹了几次人机验证 → 开语音或输出长文看会不会中途断 → **晚上九点到十一点重跑一遍**。四步都过才算适合你，白天的表现不作数。

## 八、FAQ

**免费节点能跑吗？** 跑不动。公开节点被几千人共用，评分见底，验证码一直弹，省的钱赔的是时间。

**日本还是新加坡？** 日本延迟略低、IP 资源更丰富；新加坡线路质量参差。两个都在名单里，看你买的那家在哪边节点做得细。

**账号被停用了换机场能救吗？** 不能。停用是账号侧的处理结果，换线路不恢复，该处理的是新号的注册环境，参考[ChatGPT 国内怎么用](https://huanghaiwan.com/ai/chatgpt-access-guide/)那篇。

**要不要上年付？** 第一年别。AI 可用性是动态的，先月付跑满两个月，晚高峰没崩、验证码没变多，再考虑季付。
