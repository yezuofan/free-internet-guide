## 一、AI写周报（每天省25分钟）

### 核心逻辑

不是让AI替你编，是你把本周干的活**粗略说出来**，让AI帮你整理成漂亮的周报格式。

### Claude/ChatGPT提示词模板

```
你是一位专业的职场写作助手。请将以下工作内容整理成一份专业的周报/日报。

要求：
- 分点列出，重点突出
- 量化成果（有数字更好）
- 用正式但不过于刻板的语气
- 突出本周已完成的成果
- 下周计划单独列出

以下是我本周的工作内容（比较乱，帮我整理）：
{{把你做的事情随便写在这里，一段话也行、关键词也行}}
```

### 进阶用法：AI周报自动生成流

用Claude的Projects或ChatGPT的GPTs功能，可以创建一个专门的**周报生成器**：

1. 在ChatGPT中创建一个GPT，设定角色为"周报助手"
2. 把你的日常工作内容（Jira工单、Git commits、邮件）丢进去
3. AI自动按周报格式输出

> 这项功能需要ChatGPT Plus订阅（$20/月）。推荐搭配**龙猫云**或**万达云**使用，每月¥15-17搞定网络 + ChatGPT全功能访问。

## 二、AI做PPT（每天省1.5小时）

### 方案一：Gamma.app（强烈推荐）

[Gamma.app](https://gamma.app) 是目前最好的AI生成PPT工具。

**优势：**
- 一句主题描述 → 自动生成完整PPT（含大纲、配图、排版）
- 支持中文内容
- 免费版就能用（生成有限制）
- 可导出为PPT/PDF格式

**操作步骤：**

1. 打开 gamma.app，点击"Create with AI"
2. 输入主题（中文就行），比如："人工智能在电商行业的应用"
3. 选择风格模板（Professional / Creative / Minimal）
4. Gamma自动生成大纲 → 确认 → 生成完整PPT
5. 手动微调细节文字和图片
6. 导出为PPT文件

**提示词模板：**

```
帮我生成一份关于[你的主题]的演示文稿。
要求：
- 8-10页
- 受众：公司管理层
- 风格：专业简洁
- 语言：中文
- 每页不要太多字，每个点不超过20字
```

### 方案二：用ChatGPT/Claude写大纲 + 手动做

如果不想用Gamma，也可以用AI写大纲你来做：

```
你是一位PPT内容策划专家。请为以下主题设计一份演示文稿的内容框架。

主题：[填写你的主题]
受众：[填写听众群体]
时长：[填写预计演讲时长]

要求：
1. 设定一个有记忆点的演讲主线
2. 每页只讲一个核心观点（不超过20字）
3. 每页都有具体的数据/案例支撑（编的也可以，标注"待替换"）
4. 最后一页是行动号召

请输出每页的标题和核心要点，以及建议的配图方向。
```

### Claude Code：最强AI编程助手

Claude Code是Anthropic推出的终端版AI编程工具，直接在你的项目里运行，能读文件、改代码、跑git。

**常用指令示例：**

```
# 写一个新功能
/start 帮我写一个用户登录的JWT验证中间件，Express + TypeScript

# 修bug
Debug一下为什么/api/login返回503，查服务端日志

# 重构
把这个controller拆分一下，职责太多了

# 写测试
给userService.ts写单元测试，覆盖率80%以上
```

### AI编程的核心技巧

**最重要的一个原则：不要等AI替你做决定。**

最佳用法：
1. **你负责设计**（架构/逻辑）→ 你告诉AI要做什么
2. **AI负责执行**（写代码）→ AI生成实现代码
3. **你负责校验**（review/测试）→ 你确认代码正确

**提示词模板：**

```
我用[技术栈]，要实现[具体功能]。
约束条件：
- 错误处理要完整
- 性能优先（O(n) > O(n²)）
- 不要引入新依赖
- 写TypeScript类型定义
- 包含单元测试

功能描述：[详细描述]
```

## 常见问题

### Q：这些AI工具国内都能用吗？

A：ChatGPT、Claude、Gamma.app、Cursor都需要代理才能访问。GitHub Copilot在国内可以直连，但速度较慢。建议配置一个稳定的代理服务——文中推荐的**龙猫云**、**万达云**都经过实测，一次配置所有AI工具全通。

### Q：免费的AI够用吗？

A：够用但有限制。ChatGPT免费版可以用GPT-3.5和有限次数的GPT-4o，写周报完全OK。Claude免费版有每日次数限制，重度使用建议付费（$20/月）。

### Q：AI写的内容能直接用吗？

A：**不能照搬。** AI生成的周报、PPT、代码，都需要人工review一遍。AI擅长"搭框架"和"写草稿"，最后的把关和润色得自己来。

### Q：写代码用AI，代码质量靠得住吗？

A：取决于你review得多认真。AI生成的代码一般结构上没问题，但可能有：
- 过度工程（写了很多你根本不需要的抽象）
- 安全漏洞（没做输入验证、SQL注入防护）
- 依赖版本过旧

**核心规则：信任但验证。** 每个AI生成的commit都diff一下再提交。
