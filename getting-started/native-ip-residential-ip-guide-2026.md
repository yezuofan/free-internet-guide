## 一、四个词，两条轴

「原生」和「住宅」不是同一件事。

- **分配方式**：原生 IP 是当地注册机构直接把地址段分给使用它的运营商或公司，注册地和实际使用地同国；广播 IP 是地址段注册在 A 国、靠 BGP 宣告到 B 国机房跑，注册地和位置错开。
- **持有主体**：住宅 IP 是宽带运营商分给家庭用户的地址；机房 IP 是数据中心整段买断的。

两条轴交叉出四种，其中「广播 + 住宅」在商业上基本做不出来：

| 组合 | 通俗说法 | 典型场景 |
|:--|:--|:--|
| 原生 + 住宅 | 真「原生住宅 IP」 | 海外家宽、高端独享套餐 |
| 原生 + 机房 | 本地机房 IP | 正规云服务器、部分专线落地 |
| 广播 + 机房 | 落地 IP / 中转 IP | 中转线路的出口段 |
| 广播 + 住宅 | 几乎不存在 | 成本上不成立 |

所以「全节点原生 IP」这话可能是真的，但它讲的是第二种——本地的机房 IP。拿它去养号、开店铺，八成要失望。

## 二、三分钟自己验

1. **查归属**：连上节点后看 `ipinfo.io` 或 `ip.sb` 的 `org`（ASN 组织名）和 `country`（注册地）。
2. **看类型**：org 里出现 Cloud / Hosting / Data Center / Server / VPS → 机房段；出现 Telecom / Broadband / Cable / Mobile 或 ISP 品牌名 → 住宅或移动段；country 跟节点标注地区不一致 → 广播 IP。
3. **实测**：打开一部只在当地上线的版权剧（能播才算解锁），再登录一次 ChatGPT 或 Claude 看有没有弹人机验证。

查的时候别用浏览器插件自带的检测，它读的可能是浏览器缓存的位置信息，不是真实出口。另外记得先关 IPv6，否则部分流量从本地直连出去，查到的不是节点地址。

- **暮光加速九档只有 ¥109 年付轻量版写了原生 IP**；MESL 各档写的是「170+ 节点**和**家宽节点」，家宽是其中一部分；TAG 六档只有 ¥999 定制给「1 个当地住宅 IP」。

## 四、六种说法翻成人话

| 商家写法 | 实际意思 |
|:--|:--|
| 原生 IP | 注册地与机房同地，没说是不是住宅 |
| 纯正 / 纯净住宅 IP | 强调不是广播段、不是机房段 |
| 家宽节点 | 节点池里有一部分走家庭宽带，不代表全池 |
| 机房 IP + ISP 住宅 IP | 两种都有，按需挑节点 |
| 100% 原生住宅 IP | 语气最强，可以要求客服给 ASN 截图佐证 |

## 六、三个常被问到的

**IP 显示机房，商家说是住宅？** 先确认测的是不是同一台节点，一个订阅里二三十个节点混着两种属性很常见。换几个再查还是一样，那就是宣传夸大。

**共享住宅 IP 能用吗？** 看剧、日常浏览能。开店、养号、长期挂 AI 服务不建议——你不知道池子里其他人在干什么。一个被邻居搞脏的共享住宅池，实际表现经常不如干净机房段。

**原生 IP 会变吗？** 会。换 IP 段、搬机房、上游调路由都可能让一段地址从干净变脏。这也是没有「永远干净」名单的原因，只能学方法。
