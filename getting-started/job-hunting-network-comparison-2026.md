## 为什么求职季的网络不能凑合

**1. 线上笔试是「全程联网 + 双机位」。** 今年秋招国企线上笔试的要求写得很直白：两台设备同时在位，一台电脑答题、一台手机做第二视角监控，考试期间须实时联网，考试系统在网络连通状态下自动保存作答。断网那几分钟你既答不了题，还得处理重连——笔试倒计时不会等你。更麻烦的是提前下载考试客户端、试考调试这两个环节，网络不稳的人往往正式考试当天才发现客户端装不上。

**2. 视频面试卡顿有三层原因，多数人只盯着第一层。** 一次远程面试包含网络传输、会议软件、音视频采集、显示扩声四个环节，卡顿可能来自任何一层：无线网不稳、多人共享出口、离路由太远是网络层；摄像头调用失败、拾音异常是设备层；临时测试、逐个恢复是部署层。多数人的解法是换个麦克风，真正的变量常常在链路。

**3. 海外招聘平台和测评平台，根子在海外。** 外企、海外岗位、远程岗位的招聘链路几乎全在境外：LinkedIn、Indeed、Workday、Greenhouse、Lever，以及 HackerRank、CodeSignal、Codility 这类在线测评平台。共同点只有一个——国内直连时快时慢，而你只有一次机会。

**4. 账号环境比速度更容易被忽略。** 领英账号、海外招聘平台账号一旦被判定异常登录，轻则弹验证、要求改密码，重则临时冻结。出口 IP 今天香港、明天美国、后天新加坡地乱跳，是最典型的触发信号。账号安全讲究 IP 归属稳定，这和速度是两件事。

**5. 求职期的设备从来不止一台。** 电脑答题、手机监控，面试可能还要备一台平板；宿舍里还有舍友在打游戏、刷视频。入门档限 3-5 台，刚好卡在你最需要的时候。晚八点全宿舍抢网，正是笔试面试最容易撞上的时间。

## 面试前 24 小时网络自查清单

1. **测速要在对的时间做。** 晚上八点到十点、也就是你真正考试的时间段，测一遍延迟和丢包。
2. **确认客户端开着 TUN 模式。** 浏览器能访问不代表考试客户端能访问——系统代理只接管浏览器，独立的考试客户端默认不走线路。
3. **双机位设备一起测。** 电脑和手机同时在线，看是否互相抢带宽，尤其是宿舍共享网络。
4. **备用方案要真的能用。** 手机热点提前试一次，确认热点下考试客户端能启动，别等断网那一刻才第一次尝试。
5. **关掉后台下载与自动更新。** Windows 更新、Steam、网盘同步在面试中途占满带宽，是最常见的翻车原因。
6. **面试当天别换线路或换节点。** 领英、招聘平台、测评平台对登录环境敏感，保持与投递简历时一致的出口地区，减少触发风控的概率。

## FAQ

**Q1：在线笔试中途断网怎么办？**
考试系统一般会在网络连通状态下自动保存作答，重连后接着答即可。要做的是尽快恢复网络（切备用热点最快），再把情况反馈给监考。预防比补救重要，见上面的自查清单。

**Q2：视频面试卡顿先排查什么？**
按「网络 → 设备 → 软件」的顺序：先换一条对 UDP 友好的线路（优先 IEPL 专线），再看摄像头麦克风是否被其他程序占用，最后检查会议软件版本与共享屏幕设置。无线不稳时，网线直连是成本最低的改善手段。

**Q3：投国内公司需要准备跨境网络吗？**
不需要。国内招聘平台、国内测评系统、腾讯会议都有本地服务，直连正常。需要跨境网络的场景是投外企或海外岗位、访问境外招聘系统与测评平台、参加海外团队视频面试，以及用 ChatGPT、Claude 做模拟面试和简历润色。

**Q4：一家服务够用还是必须买两家？**
只投国内加少量外企，一家不限设备的够用；同时投多家外企、账号资产多的话，主力 + 备用两条线路更稳——面试当天线路出问题的概率不高，但一旦撞上，代价是这一轮机会。
