# Clash 客户端怎么挑机场：订阅格式、协议兼容与节点分组（2026）

> 大多数人挑机场只看价格、流量、稳不稳，这三件事对 Clash 用户只解决一半问题。真正会天天折腾你的是：订阅能不能直出 YAML、节点名有没有地区前缀、内核吃不吃 Hysteria2、设备数够不够多端同时在线。这篇从客户端这一侧讲清楚怎么挑。

**更新时间：2026年11月8日**

## 一、Clash 选机场，多出四个判据

| 关注点 | 只看价格流量的人 | 用 Clash 的人 |
|:--|:--|:--|
| 订阅格式 | 能导入就行 | 必须直出 Clash YAML，不接受二次转换 |
| 节点命名 | 无所谓 | 必须有地区前缀，否则规则组写不出来 |
| 协议 | 无所谓 | 内核版本决定 Hysteria2 / TUIC 能不能吃 |
| 设备数 | 一台电脑够用 | 电脑 + 手机 + 平板 + 软路由，四个端起 |
| 倍率 | 看总流量 | 看晚高峰倍率，1.0x 和 0.3x 差三倍体感 |

### 1. 订阅得能直出 YAML

廉价机场常只给一条 Base64 通用订阅，Clash 用之前得挂 subconverter 转。转换会丢节点名规范、丢掉机场预置的策略组。判断方法：后台订阅页有没有单独的「Clash」按钮或一键导入入口。

### 2. 节点名要有地区前缀

`url-test` 策略组是按地区建的，你不知道节点叫什么就写不出 `proxies: ["香港 01", "香港 02"]`。只能 `include-all` 全塞进去，结果自动组里混进美国节点，测速一抖就跳美西。

### 3. 内核决定协议上限

Clash Verge Rev、ClashX Meta、Stash、OpenClash 现在都跑 Mihomo 内核，SS / VMess / Trojan / VLESS Reality / Hysteria2 / TUIC 全吃。还停在 Clash for Windows 的话，原版 Premium 内核只认 SS、VMess、Trojan 三类 —— 买主打 Hysteria2 的机场，导进去一片红叉，不是机场坏了。

### 4. 设备数别信「不限设备」

自由猫是分档的：¥8/30GB 只给 1 台、¥12/100GB 给 3 台、¥19.9/200GB 给 10 台，到 ¥32.8/400GB 和 ¥59.9/1000GB 才真正不限。只挂最低档又想全屋十来台，登录第四台就掉线。

## 三、订阅导入后要做的三件事

1. **先看节点名**。全是 `HK-01` 这种编号，回后台找找有没有「完整版」订阅（有些机场精简版和完整版两条链接并存）。
2. **策略组建三到四个就够**：`自动选择`（url-test 全节点兜底）、`流媒体`（select 指向解锁节点）、`AI 工具`（select 指向原生 IP）、`直连`（DIRECT）。规则从上往下匹配、命中即停，宽泛规则放后面。
3. **桌面软件走 TUN**。浏览器能连不代表整机都通，命令行工具、游戏启动器大多不认系统代理。

## 四、五个坑

- **Base64 订阅直接粘进 Clash** → 报 `yaml: unmarshal errors`，Clash 要 YAML。
- **老内核硬刚新协议** → CFW 导入 Hysteria2 节点整行飘红，换 Verge 立刻正常。
- **`include-all` 用上瘾** → 110 个节点一起 url-test，测速跑十几秒，中途任何节点抽风都引发重排，播放器就是一次缓冲。
- **只买最低档试** → 最低档普遍限设备、限速、限并发，体验不代表全局，至少买中间档。
- **订阅到期没提醒** → Clash 不会提示，到期当天全节点一起红，容易误判成机场跑路。
