7月29日，微软CEO萨提亚·纳德拉在财报电话会上确认：Copilot超级应用**2026年内上线**，整合Chat对话、GitHub编程、Cowork协作和Autopilot智能体四大能力。

## 什么是Copilot超级应用

微软把过去分散在四个独立产品中的AI能力——Copilot Chat、GitHub Copilot、Copilot Cowork、Copilot Autopilot——全部整合进同一个原生应用。一次登录，聊天、写代码、自动执行多步骤工作流在一个上下文里完成。

**不再需要记四个入口、四个订阅、四个界面。**

## 跟现在有什么区别

| 现在 | 超级应用后 |
|:----|:----------|
| Copilot Chat=浏览器 | 统一入口 |
| GitHub Copilot=VS Code | 一个App写代码 |
| M365 Copilot=Office | 一个App写文档 |
| Copilot Cowork=Teams | 一个App协作 |
| 各管各的，来回切换 | 上下文贯穿所有场景 |

## 什么时候能用

2026年Q4（10-12月），先Win/Mac桌面版，再移动端和Web。

## M365 Copilot已超3000万付费席位

每3个Office 365企业用户中就有2个开启了Copilot Pro，微软这一季度Azure AI服务收入同比增长87%。超级应用是AI从"功能堆砌"到"操作系统级整合"的关键一步。
